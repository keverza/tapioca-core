# Public test project

This directory is reserved for the small Archicad project used by the public
example integration tests. The project file must be authored and anonymized in
Archicad before it is committed; a synthetic placeholder would not verify the
add-on against a real model.

When the fixture exists, keep the procedure and expected outputs beside it and
run the examples against it from a clean public clone. The offline dry-run and
C++ tests do not require this project.
