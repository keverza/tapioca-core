Development

Build the public core. Validate the seams.

The add-on is Windows-only. The public repository keeps native code, the shipped Python package, examples, tests, and build tools together.

Prerequisites

Prepare the machine before the first build.

01

Windows toolchain

Visual Studio with C++ tools, the MSVC v143 x64/x86 toolset, C++ ATL for v143, CMake, and Node.js/npm.

02

Archicad 29

Install Archicad 29 and keep it closed while building. Live verification also needs a licensed interactive desktop session.

03

Python 3.12

Use Python 3.12 for the development environment and install the development requirements from the repository root.

04

Reference tree

Provision the catalog-listed AC29 DevKit and dependencies into the ignored AddOn/reference tree.

Build from source

Provision, build, then sync commands.

Run from the public repository root in Windows PowerShell. The reference provisioner fills the ignored dependency tree; the build produces the AC29 add-on.

PowerShell
python -m pip install -r dev-requirements.txt

powershell -File tools/build/provision-reference.ps1 -FromUpstream
powershell -File tools/build/Build-AddOn29.ps1
powershell -File AddOn/EvP/Sync-Commands.ps1
