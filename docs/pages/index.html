import tapioca

@tapioca.command(
    title="Hello Tapioca",
    category="Examples",
)

    name: tapioca.Text = "Archicad",
):
    tapioca.ui.text("Hello, " + name)

A focused bridge

Python at the edge. Archicad in control.

Tapioca keeps model access in a native Archicad add-on while giving command authors a small, readable Python surface. You can start with a script that needs only the current selection and grow into typed inputs, properties, geometry, and native commands.

The short path

Everything needed for a first useful command.

No framework or build step is required for command authoring.

01

Install the runtime

Load the AC29 add-on, provision its managed Python runtime, and sync the public examples into the palette.

→ 02

Author a command

Put a scanner-readable command.py in an example or command folder and describe its inputs with Python.

→ 03

Use the API safely

Read selections and properties through the Python facade. Native calls stay behind the main-thread boundary.

→

Learn by example

Small commands, real model questions.

The repository examples are intentionally narrow. They are useful as a first read, a smoke test after installation, and a starting point for your own workflows.
