Get started

From a clean checkout to a visible command.

Install the release, sync the public examples, and use the palette to prove the connection before writing your own workflow.

01

Download the add-on

Download Tapioca_AC29_Win.apx from the GitHub Releases page. Keep a checkout of the repository nearby because the runtime installer and examples live there.

02

Install the managed runtime

With Archicad closed, run these commands from the repository root in Windows PowerShell:

PowerShell
powershell -NoProfile -ExecutionPolicy Bypass -File .\dist\Install-Runtime.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\AddOn\EvP\Sync-Commands.ps1

The first command installs the bundled CPython runtime and baseline packages under %LOCALAPPDATA%\Tapioca\runtime. The second copies commands to %LOCALAPPDATA%\Tapioca\Commands.

03

Load Tapioca in Archicad

Open Archicad 29, go to Options > Add-On Manager, add the Tapioca and Tapir add-ons, then open the Tapioca palette from the Window menu.

04

Run the first example

Press Rescan in the palette. Choose Hello Tapioca, accept the default value, and run it. A successful result means the add-on, managed runtime, command sync, and palette scanner are connected.

Your first file

Commands are just folders with a contract.

Copy this file to Examples\HelloCommand\command.py or use the existing example as your starting point.

command.py
import tapioca

@tapioca.command(
    title="Hello Tapioca",
    category="Examples",
)
def run(name: tapioca.Text = "Archicad"):
    tapioca.ui.text("Hello, " + name)

When something is missing

Check the boundary before changing the command.

Command is not listed

Run AddOn\EvP\Sync-Commands.ps1, then press Rescan. The scanner silently omits files that do not follow the command shape.

Native changes are invisible

Rebuild the add-on, close and restart Archicad, and reload the .apx. A loaded add-on can lock build outputs.

Runtime is missing

Run dist\Install-Runtime.ps1 with Archicad closed. It provisions Tapioca's runtime rather than modifying external Python.

For the complete machine setup, see the repository setup guide.
