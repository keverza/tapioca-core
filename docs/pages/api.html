Three callable families

Use the namespace that owns the capability.

Tapioca.*

Native Tapioca commands

Use this canonical namespace for commands implemented by Tapioca's controlled native boundary.

tapioca.api.call("Tapioca.Name", params)
API.*

Official Archicad JSON API

Call the official API wrapper when the capability belongs to Archicad's JSON surface.

tapioca.api.call("API.Name", params)
Tapir.*

Tapir add-on commands

Route capabilities provided by the companion Tapir add-on through the same facade.

tapioca.api.call("Tapir.Name", params)

Compatibility: EvP.* remains accepted at the dispatcher boundary for unmigrated consumers. New callers and documentation use Tapioca.*.

Important by design

Small requests. Explicit contracts. No hidden BIM mirror.

Ask for a selection, representation, properties, and execution intent. A snapshot or cache can support a workflow, but it does not replace Archicad as the source of project meaning.

  • Python never calls ACAPI directly.
  • Archicad-dependent work stays on the controlled main-thread path.
  • Native success payloads contain domain data, not transport fields.
  • Batch writes use one transaction and one user undo step.
