# Examples

These commands are deliberately small. Each one demonstrates one public Tapioca
surface without depending on the development workspace or a client project.

Run the examples from the palette after syncing the public command roots. The
same folders can be passed to `AddOn/EvP/tests/dryrun_command.py` for an offline
wire-level dry run.
